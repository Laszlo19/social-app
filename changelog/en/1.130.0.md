# Version 1.130.0

- **Translator badges** – contributors who help translate the app now get a language badge on their profile. Tap or hover it to see which languages they translate and proofread.
- **Help translate the app** – a new banner and a *Help translate the app* option under Settings → Languages invite you to join the localization project.
- **Advanced search filters are now standard** – the advanced filter dialog is always available from the search screen, so the beta toggle for it is gone.
- Upgraded to Bluesky **1.130.0**, with fixes and improvements from upstream.
